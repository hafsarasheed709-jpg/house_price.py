# House Price Prediction

Ye project machine learning (Linear Regression) use karke house prices predict karta hai.

## Project ke bare mein
Boston Housing dataset use kiya gaya hai. Dataset mein house ki size, rooms, location wagera 
ke features hain jinke basis par price predict kiya jata hai.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Steps
1. Dataset load kiya
2. Data clean kiya
3. Data ko train aur test mein divide kiya
4. Linear Regression model train kiya
5. Model ki accuracy check ki
6. Actual vs Predicted price ka graph banaya

## Result
Model ne house prices predict karne mein achi accuracy dikhai.
